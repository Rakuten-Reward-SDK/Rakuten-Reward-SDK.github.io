# アプリの言語

Rakuten Reward SDKは5つの言語をサポートしています：

| 言語 | コード |
|---|---|
| 日本語 | `ja` |
| 英語 | `en` |
| 韓国語 | `ko` |
| 繁体字中国語 | `zh-hant` |
| 簡体字中国語 | `zh-hans` |

デフォルトでは、SDKはデバイスのロケールで表示されます。アプリが特定の言語のみをサポートしている場合、SDKの画面がアプリの他の部分と異なる言語で表示されることがあります。`setAppLanguage` を使用して一貫したエクスペリエンスを維持してください。

## アプリの言語を設定する

```swift
RewardConfiguration.setAppLanguage("ja") // 日本語
```

## デバイスのデフォルトに戻す

空文字列を渡すと、SDKがデバイスのロケールに従うようになります：

```swift
RewardConfiguration.setAppLanguage("") // デバイスのデフォルト
```

指定した言語がSDKでサポートされていない場合、**日本語**にフォールバックします。
